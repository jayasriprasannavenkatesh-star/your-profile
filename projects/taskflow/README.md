# TaskFlow

A premium, responsive productivity dashboard built with vanilla HTML, CSS and JavaScript.

## Features
- Add tasks with priority
- Mark tasks complete
- Completion progress tracking
- Clear completed tasks
- LocalStorage persistence
- Responsive UI
- Keyboard-friendly task entry

## Tech Stack
HTML5 · CSS3 · JavaScript · LocalStorage

## Run
Open `index.html` in a modern browser.

## Project Focus
This project demonstrates frontend fundamentals, DOM manipulation, state management, accessibility-minded UI and polished product design without a framework.
